# 学生状态管理系统 · 部署说明

适用：Windows 10/11 x64，端口固定 `3210`。
发布包已经带前端产物和 Windows 预编译依赖，目标机不需要装编译环境。

---

## 一、全新安装（空数据）

### 1.1 一键部署（推荐）

1. 把 `student-status-board-<版本>.zip` 拷到新电脑，**右键 → 全部解压缩**到本地目录，例如 `D:\student-status-board`。
   - 路径带空格/中文可以，但**不要放 OneDrive、坚果云等同步目录**（SQLite WAL 会被同步搞坏）。
   - 不要在压缩包里直接双击——那样会解到临时目录，脚本会提示找不到程序文件。
2. 双击解压目录里的 **`一键部署.cmd`**。
3. 它会先问「开始部署？[Y/N]」，按 `Y`；
4. 弹 UAC 时点「是」（装依赖、放行防火墙、注册备份任务都需要管理员）；
5. 按提示设置登录密码（至少 6 位，输入时不显示）；
6. 装完问「现在启动服务？」，按 `Y` 直接开，或 `N` 稍后自己启动。

全程一个窗口，不用开 PowerShell、不用 `cd`、不用粘命令。

装完桌面会有三个快捷方式：`学生状态管理系统`（打开菜单）、`启动学生状态管理系统`（直接启动）、`重置登录密码`。
快捷方式没建出来也不影响，双击项目根目录的 `学生状态管理系统.cmd` 就是同一个入口。

菜单项：`1` 启动 / `2` 停止 / `3` 重置密码 / `4` 绑定 Tailscale / `5` 允许局域网访问 / `6` 检查更新 / `7` 局域网测试模式 / `8` 一键部署（修复安装）。

`一键部署.cmd` 可以重复跑，等于「修复 / 重新配置」，**已有数据和登录密码不会被动**。
额外参数会原样转给 `install.ps1`，例如：

```bat
一键部署.cmd -SkipTailscale -SkipBackupTask
一键部署.cmd -TailscaleAuthKey tskey-auth-xxx -InstallTailscale
```

### 1.2 命令行部署（可选）

已经有管理员 PowerShell、想自己控制参数时：

```powershell
cd D:\student-status-board
powershell -ExecutionPolicy Bypass -File .\deploy\install.ps1
```

`install.ps1` 会依次做：

- 检测 Node.js ≥ 22；没有就从 npmmirror 下载 `v24.22.1` 到 `runtime\node`
- 安装生产依赖（发布包已带 `node_modules`，通常直接复用）
- 首次运行引导设置登录密码
- 在桌面创建三个快捷方式（都指向 `学生状态管理系统.cmd`，用参数区分动作）
- 监听 `0.0.0.0`，`COOKIE_SECURE=auto`（HTTPS 自动加 Secure，局域网 HTTP 不加）
- 放行防火墙 TCP 3210（仅 `LocalSubnet`，不暴露公网）
- 检测 Tailscale；给了 auth key（`-TailscaleAuthKey`）就自动登录并 `tailscale serve`，没给则用已登录状态，未登录只提示
- 注册每天 03:00 的 SQLite 备份任务
- 冒烟检查 `/api/healthz`

默认**不注册 Windows 服务、不开机自启**。需要后台常驻时加 `-InstallService`，服务也是手动启动。

> **Windows 沙盒 / 精简系统**：解压 zip 再双击 `一键部署.cmd`。沙盒里 `Expand-Archive` 常常「找得到命令但模块加载不了」，1.2.3 起解压改成先用 .NET `ZipFile`、再退 `tar.exe`、最后才用 `Expand-Archive`；另外 `@node-rs/argon2` 的原生模块依赖 VC++ 运行时（`VCRUNTIME140.dll` / `VCRUNTIME140_1.dll`），沙盒镜像里没有，安装时会从 `deploy\vcrt\` 自动补到 node.exe 旁和原生模块目录。`一键部署.cmd` 本身保持纯 ASCII，中文提示都在 `deploy\deploy-ui.ps1`，避免 cmd 切代码页后把批处理读错位。

## 二、整目录搬迁（数据、密码、API Key 全带走）

1. 旧电脑先停止服务：菜单按 `2`（或 `tools\停止服务.cmd`）。
2. 把旧电脑整个项目目录复制到新电脑，**必须包含 `data\`**：
   - `data\app.db`：学生、反馈、生成历史
   - `data\config.json`：登录密码哈希
   - `data\backups\`：每日备份和导入前快照
3. 新电脑管理员 PowerShell 进入目录，跑一次：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\deploy\install.ps1
   ```

已有 `data\config.json` 时会跳过设密码，密码、数据、服务器里加密的 API Key 都原样可用。

> 旧电脑和新电脑不要同时运行同一份数据；需要两边都用时，用 JSON 备份导入到其中一边。

## 三、只搬业务数据（JSON 备份）

1. 新电脑按「一、全新安装」装好并设置新密码。
2. 旧电脑：设置页「备份与恢复 → 导出全部」，得到 `student-status-board-YYYY-MM-DD.json`。
3. 新电脑：设置页「备份与恢复 → 选择 JSON 备份文件」：
   - 服务端先校验文件并列出**同名同校冲突**
   - 每个冲突单独选「新建」或「覆盖」，覆盖要勾选确认
   - 导入前会自动把当前库快照到 `data\backups\pre-import-*.db`
4. 导入完成后重新填一次大模型 API Key（JSON 故意不包含 Key 和模型设置）。

## 四、Tailscale（跨网访问，一条命令绑定）

项目可以**自己绑**：装 Tailscale → 用 auth key 加入 tailnet → 配 `tailscale serve`，一条命令跑完。

### 1. tailnet 先开两个开关（只做一次）

<https://login.tailscale.com/admin/dns> → 打开 **MagicDNS** 和 **HTTPS Certificates**。HTTPS 不开，`serve` 拿不到证书，手机打不开。

### 2. 生成 auth key（只做一次）

<https://login.tailscale.com/admin/settings/keys> → **Generate auth key**：

- **Reusable**：勾上（换机器/重装还能用）
- **Pre-approved**：勾上（否则新设备要管理员在后台手动批准）
- **Ephemeral**：**不要勾**（设备离线后会被自动移除，家用服务器会掉线）
- 有效期按需（最长 90 天）；到期后生成新 key，重跑一次绑定脚本

key 形如 `tskey-auth-kXXXXXXXX-XXXXXXXXXXXXXXXX`。

### 3. 绑定

菜单按 `4`（或 **`tools\绑定Tailscale.cmd`**），按提示粘贴 key（输入不回显）。没装 Tailscale 会自动静默安装。

命令行等价：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\tailscale-bind.ps1 -AuthKey tskey-auth-xxx -Install
```

已经装好并登录同一 tailnet 的机器，不用 key：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\tailscale-bind.ps1
```

安装系统时一起绑：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\install.ps1 -TailscaleAuthKey tskey-auth-xxx -InstallTailscale
```

### 4. 结果

脚本打印 `https://<机器名>.<tailnet>.ts.net`，并写入 `logs\tailscale-url.txt`；之后双击启动，窗口里会多一行「跨网访问」。

- 手机/外面电脑：装 Tailscale，登录**同一个账号**，打开这个地址
- 只配 serve 不碰登录：仍可用 `deploy\tailscale-serve.ps1`
- 换机器名 / 换 tailnet：重跑一次绑定脚本拿新地址
- 查看状态：`deploy\tailscale-bind.ps1 -StatusOnly`

## 五、访问地址

- 本机：`http://127.0.0.1:3210`
- 同一 Wi-Fi 手机：`http://<电脑局域网IP>:3210`
  - 启动窗口会列出局域网地址
  - 也会写到 `logs\access-urls.txt`
  - 或在 PowerShell 执行 `ipconfig`，看「无线局域网适配器 WLAN」的 IPv4 地址
- 跨网：`https://<机器名>.<tailnet>.ts.net`（需 Tailscale）

打不开时先确认：服务在运行、手机和电脑同一 Wi-Fi、防火墙已放行（安装脚本会自动加规则，也可菜单按 `5`）。

## 六、安卓 App

- APK 在 `release\StudentStatusBoard-1.0.0.apk`，侧载安装。
- 首次启动会让你填服务器地址，填 `https://<机器名>.<tailnet>.ts.net`。
- 已安装的 App 在加载失败页有「修改服务器地址」入口，换电脑/换地址不用重装。
- App 只接受 HTTPS，所以跨网地址必须走 Tailscale；局域网 HTTP 用手机浏览器打开即可。

## 七、常用参数

```powershell
# 只看计划，不写任何东西
powershell -ExecutionPolicy Bypass -File .\deploy\install.ps1 -DryRun

# 先不配 Tailscale / 不建备份任务
powershell -ExecutionPolicy Bypass -File .\deploy\install.ps1 -SkipTailscale -SkipBackupTask

# 额外注册 Windows 服务（手动启动，不开机自启）
powershell -ExecutionPolicy Bypass -File .\deploy\install.ps1 -InstallService

# 新电脑完全没网：先从旧电脑把 runtime\node 整个目录拷过来
powershell -ExecutionPolicy Bypass -File .\deploy\install.ps1 -SkipNodeInstall
```

脚本幂等：重复执行只会重新配置，不会重复建快捷方式/服务/任务，也不会重置密码和数据。

## 八、忘记登录密码

菜单按 `3`（或桌面上的「重置登录密码」快捷方式）：

1. 输入 `RESET` 确认；
2. 输入新密码两遍（至少 6 位）。

重置后会：

- 旧 `data\config.json` 自动备份成 `data\config.json.bak-<时间戳>`
- 已登录设备退出登录
- 服务器保存的大模型 API Key 清空（加密密钥由密码哈希派生），需要到设置页重新填写
- 学生、反馈、生成历史不受影响

也可以管理员 PowerShell 跑：

```powershell
node scripts\reset-password.js
```

如果提示数据库被占用，先菜单按 `2` 停服务，再跑一次。

## 九、验证与卸载

验证：

```powershell
Invoke-RestMethod http://127.0.0.1:3210/api/healthz
# 期望：ok=True db=True
```

卸载（保留 `data\`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\uninstall.ps1
```

- 默认停服务、删 Windows 服务、每日备份任务和桌面快捷方式，**保留数据**
- `-RemoveLogs` 清日志，`-RemoveRuntime` 清自动下载的 Node
- `-ResetTailscale` 清 `tailscale serve` 规则
- `-PurgeData` 才会连 `data\` 一起删（需输入 `DELETE` 确认）

## 十、GitHub 更新（可选）

发布包里的 `deploy\release.json` 默认是占位符 `owner/name`，只能用手动更新包：

1. 把新版 `student-status-board-<版本>.zip` 和配套 `version.json` 放进安装目录的 `updates\`
2. 菜单按 `6`（`tools\检查更新.cmd`）

配置真实 GitHub 仓库后，`tools\检查更新.cmd` 会自动比版本、下载、校验、停服务、备份、替换、起服务，失败回滚。
